# Changelog

## [0.2.0-alpha3]

### Added
- Interactive preview card flipping.
- Theme selection for card backs.
- Live deck preview status panel.
- Separate preview and print renderers.

### Changed
- Rebranded application from Convoy Conversations to Trail Talk.
- Reduced printed card size to 2.4 × 3.4 inches for lamination.
- Improved card back tagline layout.
- Refactored utility functions into utils.js.
- Separated theme assets into dedicated modules.

### Fixed
- Print layout now uses paired front/back pages.
- Hole punch guide only appears on card backs.
