# Trail Talk

**Real Questions. Real Connections.**

Trail Talk is an open-source browser application that generates printable
conversation decks for overlanding, camping, road trips, and other shared
adventures.

Each deck is reproducible from a seed, printable on standard letter paper, and
organized into themed categories that encourage meaningful conversation rather
than small talk.

---

## Features

- Deterministic deck generation
- Printable poker-sized conversation cards
- Interactive deck preview
- Theme support
- Printable deck manifest
- Offline operation
- Browser-based (no server required)

## Project Principles

Trail Talk is built around a small set of engineering principles:

- Secure by Design
- Accessibility First
- Declarative Themes
- Portable Deployment
- Separation of Concerns
- Reproducible Deck Generation
