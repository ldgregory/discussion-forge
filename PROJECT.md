## Version 0.2 Design Decisions

Printing
- Six playable cards per page
- Front pages immediately followed by matching back pages
- Cut guides on backs only
- Hole-punch guide: front top-right, back top-left
- Card size: 2.40" × 3.40"

Card Back
- Trail Talk
- Real Questions. Real Connections.
- Navy background
- White compass rose
- White dashed trail
- Red destination flag

Architecture
- JSON catalog
- UUID card identities
- Permanent deck positions
- Seeded deck generation
- Manifest output
